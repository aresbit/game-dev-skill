## 3. window.* globals produced / consumed across the bridge
PRODUCED by custom JS, CONSUMED by engine:
  window.__lpLang        (string)  set by page head bootstrap; read by _LPWebGetLang
  window.__lpSetLang     (fn)      defined by body bootstrap; called by _LPWebSetLang (switches page + writes lp-lang)
  window.__lpNet         (object)  {entries:{name:{loaded,total,done,cached,status,attempt,phase,...}},failed:url}
                                   installed by LPWebLoading.installDownloadMeter(); read by _LPWebDownloadLoaded/Pending
  window.__lpFrameTrace  (object)  ring per-frame trace (schema:1, capacity:18000); written by _LPWebRecordFrame
  window.__lpStats       (object)  latest fps/ms/... snapshot; written by _LPWebReportFrame
  window.__lpJourneyMarks(array)   {phase,target,at,visibility,focus} marks; by _LPWebLoadMilestone
  window.__lpTextureDump (object)  parsed JSON; by _LPWebSetTextureDump

## 4. localStorage keys
  "lp-lang"   the player's language choice. Written by page (window.__lpSetLang, index.html:272) and read at
              startup (index.html:31). The in-game settings page writes it too via WebPlatform.jslib LPWebSetLang
              (i.e. _LPWebSetLang -> window.__lpSetLang -> localStorage.setItem("lp-lang", ...)).
  (save game: IndexedDB via Unity, autoSyncPersistentDataPath:true -> journey.json; not a localStorage key.)
