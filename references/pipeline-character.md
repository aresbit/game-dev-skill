# 角色构建流水线

- 概览
- 步骤 1：T-pose 四视图
- 步骤 2：多视图生 3D
- 步骤 3：自动绑定蒙皮
- 步骤 4：动作库接入
- 步骤 5：接触类动作精修
- 判据与产物
- 陷阱

## 概览

图像模型出人物图 → 文/图生 3D 出人物模型 → DCC 绑定蒙皮 → 动作库接入 → 复杂交互在 DCC 里二次调整（可选）。

## 步骤 1：T-pose 四视图

用图像模型出角色的 T-pose 四视图，**确保各视角细节统一**（发型、服装、配饰在每个视角都对得上）。四视图通常取正面/侧面/背面/(另一侧或 3/4 视图)。不一致就重出，别把矛盾带进 3D。

## 步骤 2：多视图生 3D

在 3D 生成服务选「多视图生成 3D」，依次上传四视图：

- 拓扑：四边形（quad）。
- 精度：拉到最高。
- 模型档位：选面向游戏/交互的档位（面数可控、结构便于编辑，利于后续绑定与动画）。

**先看白模网格是否整齐无误**：整齐 → 点「贴图（Texture）」生成纹理；不整齐 → 用「局部编辑网格（edit mesh）」再生成，别硬贴。

## 步骤 3：自动绑定蒙皮

在 DCC 里用自动绑定插件（如 Auto-Rig Pro）完成绑骨与蒙皮，**确保骨骼位置与关节对齐**。作者的提示词（原文）：

> 使用 Auto-Rig Pro 为人物完成绑骨和蒙皮，确保骨骼位置与人物关节对齐。完成后测试抬手、弯腿、转身等基础动作，检查并修正明显的变形、拉扯和穿模问题。

必须实测：抬手 / 屈腿 / 转身，逐项修变形、拉扯、穿模。

## 步骤 4：动作库接入

按关键词到动作库（如 Mixamo）搜索动作、下载 FBX。让模型**核对动作是否匹配角色真实骨骼**后接入——重点是骨骼命名与层级/朝向的对应，不能直接套。

## 步骤 5：接触类动作精修（可选）

通用动作库常常没有「人物与道具接触」的完美动作（如提着水壶）。做法：先选一个接近的基础动作，再让模型在 DCC 里迭代细节。作者的提示词（原文）：

> 请参考提供的动作库动作，保留其中适用的部分，并使用绑定插件的手臂 IK 控制器调整手臂姿势，配合手指握持和道具位置的细节修正，补全动作。确保手掌与把手接触稳定、提起过程自然，避免穿模、握持脱离或道具悬空。

## 判据与产物

- **产物**：`refs/character-4view.png`、角色 `.glb`（含 UV/纹理）、绑定文件、动作 FBX。
- **判据**：四视图一致；白模整齐；极限姿势无变形/穿模；动作重定向后骨骼无错位；接触动作无握持脱离/道具悬空。
- **交接**：角色过预算检查且基础动作通过后，才接场景与玩法代码。

## 陷阱

- 四视图细节不一致 → 3D 模型自带矛盾，绑定后更明显。
- 白模没检查就贴图 → 拓扑缺陷被纹理掩盖，绑定时爆发。
- 骨骼与关节不对齐 → 全动作变形。
- 动作库 FBX 直接套 → 骨架不适配，错位/抖动。
- 接触动作指望通用库 → 握持脱离、道具悬空。
