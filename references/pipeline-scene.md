# 场景构建流水线

- 概览
- 步骤 1：钉死参考图
- 步骤 2：资产分流
- 步骤 3：复刻 + 多机位迭代
- 判据与产物
- 陷阱

## 概览

图像模型出场景图 → agent 拆解资产并在文/图生 3D 里出件 → 编码模型操作 DCC + 引擎搭建整体环境。三段串行，上一段的产物是下一段的输入。

## 步骤 1：钉死参考图

先出一张满意的场景效果图，锁定整体画风、配色、主要物体位置。再围绕它补其它角度——尤其当场景含室内 + 室外时：

- **俯视图**：说明场景布局。
- **斜侧视图**：补充物体高度、造型、层次关系。
- 也可一次生成整体视图（多视角 + 局部细节）。

作者的可复用提示词（原文）：

> 基于上传的场景参考图，帮我生成一张该场景的全面貌参考图片，包括整体环境的多视角视图以及局部细节的展示。

判据：主图与补图之间，画风/配色/同一物体的形状必须一致；不一致先回退重出，别带着漂移往下走。

## 步骤 2：资产分流

让 agent 判断每个资产该走文/图生 3D 还是 DCC 直搭，并在图上标注待你确认。作者的提示词（原文，反引号处填实际工具）：

> 我现在要进行游戏开发，我的技术栈是 <你的栈>。你根据我们上述生成的场景参考图，帮我去深入分析哪些资产适合用 3D 生成，而哪些资产适合用 DCC 直接进行搭建。将需要生成的资产在图片中标注出来，方便我来确认。

可迁移的分流经验规则：

- **走文/图生 3D**：有机造型、雕塑感道具、重复小物件、形状复杂的独立摆件。
- **DCC 直搭**：大体量环境（地面/墙体/地形）、规则几何、需要精确尺寸或碰撞的交互物、光影与体块。
- **精细道具**：用服务里精度更高的模型档位，保证高精度细节。

## 步骤 3：复刻 + 多机位迭代

把资产与参考图交给编码模型，让它操作 DCC + 引擎搭环境、按参考图摆件、调比例与位置。作者的提示词（原文）：

> 根据上传的场景内外景多视角参考图以及生成好的 3D 资产，你来对照参考图进行完美级的复刻。要求实现和参考图一样的惊艳质感和细节还原。在实现完成后，派一个独立的审查 agent 进行多机位的场景盲审。如果发现有和参考图差异的地方，就不断地进行迭代完善。

从正面、侧面等不同角度截图自查，逐步调整布局与细节；收敛后交独立审查 agent 盲审（协议见 quality-review-and-assets.md）。

## 判据与产物

- **产物**：`refs/`（主图 + 补图）、`assets/`（导出的 3D 件）、场景工程 + 正面/侧面/俯视截图。
- **判据**：多机位截图与参考图的差异项逐条收敛；无风格漂移；资产过预算检查。
- **交接**：差异清零或列明剩余可接受差异后，才进角色构建或集成。

## 陷阱

- 只出一张图就开工 → 布局/比例无处对照，后期大返工。
- 参考图之间画风不一致 → 场景拼出来风格漂移。
- 生成资产不过预算 → 面数失控、加载慢、帧率崩。
- 无独立审查 → 执行 agent 自查会系统性放过自己的偏好误差。
