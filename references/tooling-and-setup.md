## 工具清单

按原文，制作栈分四类：

1. **DCC（建模/绑定）**：Blender。用 CLI 形式驱动；安装付费插件 Auto-Rig Pro 做绑骨蒙皮与手臂 IK 控制器。
2. **引擎**：Unity。装 Unity App 作引擎，把场景、人物、交互动效打包成完整游戏；装 Unity CLI，并在项目中装 Pipeline 包，让编码模型经**官方 Unity MCP** 直接操作 Unity 项目。
3. **文/图生 3D**：Tripo 一类服务。原文提到面向游戏/交互、面数可控的档位（Smart Mesh P2.0）与高精度道具档位（H3.1）。
4. **动作库**：Mixamo。关键词搜索、下载 FBX，重定向到角色骨架。
5. **图像模型**：出场景参考图与 T-pose 四视图。

## 替代方案（可迁移）

- **本地 text-to-3D**：TRELLIS（MIT 许可）等，不想用云服务时的等价替身。
- **DCC 侧 MCP**：blender-mcp 一类，让模型驱动 Blender；或用 Blender 自带的 Python/CLI 批处理。
- **引擎侧**：Unity 官方 MCP 有过弃用/替换的变动；若不可用，走 **Unity CLI + 命令行**。以目标引擎当时的官方文档为准。

## 原则

- 不编造 CLI 参数。写命令前先确认目标机的帮助输出与版本。
- 每个工具只记「装什么、干什么、怎么被模型驱动」三层信息，细节以官方文档为准。
- 工具可替换：流水线只依赖「DCC 可被模型驱动」「引擎可脚本化构建」两个能力，不依赖具体品牌。
